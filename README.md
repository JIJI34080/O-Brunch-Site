# O’Brunch Site

Site vitrine multilingue pour le restaurant O’Brunch, développé avec Next.js 14, TypeScript, Tailwind CSS et next-intl.

## Démarrage

```bash
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` : démarre le serveur de développement.
- `pnpm build` : crée la version de production.
- `pnpm start` : lance le serveur en mode production.

## Internationalisation

Le site utilise `next-intl` pour gérer les locales suivantes : `fr-CH`, `de-CH`, `it-CH`, `rm-CH` et `en`.

## Déploiement

Prêt pour un déploiement sur [Vercel](https://vercel.com/) :

1. Pousser le projet sur un dépôt Git.
2. Importer le dépôt dans Vercel.
3. Définir `NEXT_PUBLIC_SITE_URL` si besoin.
